## Phase 1：進階編輯功能（最優先）

> 目標：把編輯器做成「高可玩性、可快速試錯、可穩定產出」的 Plurk 個人主頁 CSS 開發器
> 範圍限制：僅針對 Plurk 個人主頁 CSS（不含私訊、通知、設定頁等其他 Plurk 介面）
> 參考來源：`docs/plurk-css-lab` 持續作為後續控制器設計方向依據

### 1.1 控制器開發路線（分階段）

- [ ] **第 1 波（基礎雙案例）**：先落地 2 個已驗證可在實際 Plurk 套用成功的控制器範例
- [ ] **第 2 波（可驗證再擴張）**：`更多樣式控制器` 僅在「plurk-css-lab + 實際 Plurk 成功」雙驗證後才排入
- [ ] **第 3 波（進階控制）**：字型、漸層、陰影、動畫等進階控制器，依成功率與可用性逐步納入
- [ ] **控制器驗收標準**：每個控制器都需附「可套用範例 + 失敗邊界 + 回退策略」
- [x] **Style feature module 基礎**：貼文外觀、河道背景與回應數徽章已建立可複用拆分模式，後續新 target 可照此擴充
- [x] **數值型控制器 Slider 化**：border width 與 response-count border radius 已改用 slider；後續寬度/透明度/字級等數值控制器沿用相同模式

### 1.2 高可玩性核心迴圈（先做）

- [ ] **即時回饋編輯迴圈**：控制器調整 <-> 預覽同步更新 <-> 可立即回退，將延遲與跳動感降到最低
- [ ] **操作歷史系統**：Undo / Redo、局部還原、重做分支保留（避免誤操作打斷探索）
- [ ] **樣式沙盒機制**：提供「暫存草稿區」先試再套用，降低破壞現有版面的風險
- [ ] **玩法導向 Presets**：針對常見個人主頁風格給出可一鍵套用的起手模板（再微調）

### 1.3 編輯器 UX 提升（與 1.2 並行）

- [ ] **屬性搜尋與快速定位**：快速找到目標 CSS 屬性與區塊
- [ ] **樣式面板分組折疊**：依個人主頁區塊分群（導覽、內容、側欄等）；可沿用 feature module 的 section 分組
- [x] **右鍵選單基礎架構**：河道與貼文右鍵選單已統一外殼、標題、section 與整排可點 trigger
- [ ] **右鍵快捷操作**：重置單一屬性、複製屬性值、貼上樣式片段
- [ ] **鍵盤快捷鍵完善**：`Ctrl+S`、`Ctrl+Z`、`Ctrl+Shift+Z` 等高頻編輯快捷鍵

### 1.4 CSS 進階處理（品質保證）

- [ ] **CSS 變數抽取**：重複值自動抽成 CSS Variables，提升維護性
- [ ] **衝突偵測與提示**：匯入 CSS 與手動調整衝突時即時提示
- [ ] **CSS Diff 檢視**：比對匯入前後與儲存前後差異，降低誤改風險
- [ ] **實際套用檢查清單**：每次發版前確認在 Plurk 個人主頁可套用、可回退；response-count 已建立實站覆寫紀錄作為範例

## Phase 2：核心體驗完善（近期優先）

> 目標：讓「編輯 → 儲存 → 匯出」主流程穩定，支撐 Phase 1 的高頻試錯

### 2.1 編輯器流程補齊

- [ ] **Flow B 完整實作**：`/editor/[id]` 動態路由，載入專案 cssContent 到 StyleManager
- [ ] **模板匯入彈窗**：進入編輯器時，若專案已有 cssContent，詢問是否匯入模板覆蓋
- [ ] **自動儲存 / 手動儲存切換**：防止編輯中意外遺失

### 2.2 個人主頁預覽體驗（桌面限定）

- [ ] **預覽範圍明確化**：僅做 Plurk 個人主頁樣式預覽，不擴增其他 Plurk 介面元件
- [ ] **桌面版開發器固定視窗**：不做手機/響應式預覽切換
- [ ] **預覽縮放**：拖曳調整預覽區域大小（桌面工作流優先）

### 2.3 匯出功能強化

- [ ] **匯出格式選擇**：純 CSS / 含註解 / 壓縮版
- [ ] **一鍵複製到剪貼簿**：改善 UX
- [ ] **下載 .css 檔案**：直接下載檔案

## Phase 3：社群與分享功能

> 目標：讓使用者能發現、Fork、互動，累積可參考的樣式案例

### 3.1 社群互動

- [ ] **Like / Star API 與 UI**：實作 Like、Star 端點與前端按鈕
- [ ] **Fork 計數顯示**：模板 / 專案卡片顯示 Fork 數
- [ ] **公開專案瀏覽頁**：`/projects` 頁面呈現 PUBLIC 專案

### 3.2 模板系統強化

- [ ] **模板詳情頁**：`/templates/[slug]` 含預覽、說明、Fork 按鈕
- [ ] **分類篩選 + 搜尋**：依 Category 篩選、關鍵字搜尋
- [ ] **官方模板標記**：`isOfficial` 標記與優先顯示
- [ ] **熱門排序**：依 likeCount / forkCount 排序

### 3.3 使用者 Profile

- [ ] **公開個人頁**：展示使用者的公開專案與模板
- [ ] **個人設定頁**：頭像、暱稱、語系偏好

## Phase 4：平台化與擴展

> 目標：長期願景

### 4.1 國際化（i18n）

- [ ] **多語系支援**：繁中 / 英文 / 日文（User model 已有 `locale` 欄位）
- [ ] **語系切換 UI**

### 4.2 效能與基礎建設

- [ ] **CDN 靜態資源**：圖片素材走 CDN
- [ ] **Edge Runtime**：API Routes 遷移到 Edge
- [ ] **E2E 測試**：Playwright 主要流程覆蓋
- [ ] **CI/CD Pipeline**：GitHub Actions 自動化建置 / 部署

### 4.3 進階功能

- [ ] **版本歷史**：專案每次儲存可追溯
- [ ] **協作編輯**：WebSocket 即時同步（長期）
- [ ] **外掛系統**：允許第三方擴充控制器
- [ ] **Plurk API 整合**：直接套用 CSS 到 Plurk 帳號（需 Plurk 開放 API）
